1. Cognitive Job & Diagnostic Context

  • Scope: Extend (Building upon our verified mandi_tracker.py Agmarknet price engine).
  • AI Components: LiveKit (WebRTC, Silero VAD), Official livekit-plugins-gnani (Gnani LiveKit Plugin: Prisma STT v3.0, Timbre TTS v2.5/v3.0 via GNANI_API_KEY), Gnani Evon 3.3 Indic LLM, and LangChain/LangGraph Dual-Loop Conversational Steering Engine.
  • Distributed Topology: Client WebRTC audio ↔ LiveKit SFU ↔ Agent Worker ↔ Gnani Speech Cloud (https://api.vachana.ai) ↔ Agmarknet data.gov.in Government Feed.
  • Trust Boundary: Untrusted audio ingestion from farmer devices; strict redaction of .env credentials (DATA_GOV_IN_KEY, GNANI_API_KEY, LIVEKIT_KEYS) at the server worker boundary.
  • Cognitive Job Statement: Deliver a voice-first Indic conversation agent that informs Indian farmers and rural traders of real-time mandi prices, nearby market price arbitrage, and MSP protection using natural spoken audio in under 1.2 seconds.

2. Definition of Done

  1. Gate M1 (Gnani LiveKit Plugin Integration): python -c "import livekit.plugins.gnani; print('Gnani plugin ready')" verifies that the official livekit-plugins-gnani STT and TTS drivers are installed and authenticated.
  2. Gate M2 (Dual-Loop Steering Engine): python -m agents.steering_router --query "झाँसी में गेहूँ का क्या भाव है?" extracts entities, pulls Agmarknet data, detects MSP comparison, and synthesizes spoken Hindi response in < 800ms.
  3. Gate M3 (LiveKit Voice Worker): python -m voice_engine.livekit_worker dev establishes a WebRTC audio loop, ingests microphone input, applies Silero VAD, and executes barge-in cancellation in < 100ms.
